# SCUM 查询中转

所有群内 SCUM 查询都通过 Windows 插件配置的 `scum.query_relay_url` 发送到 Linux 网页，不再使用 Windows 本地查询或独立 8766 服务。关键词搜索只请求一次中转搜索接口，并一次性返回其中的服务器列表；不会为列表中的每台服务器额外请求详情。输入数字服务器 ID 时只请求该服务器的详情并返回单条结果。

默认地址为 `https://ba.yooyun.top`。中转站必须提供 `/api/sync/v1/scum/query/<群号>`，并与 Windows 插件使用相同的网页同步令牌、Card Pepper 和机器人客户端绑定。查询数据由 Linux 网页服务处理。

网页更新后，同时更新并重载 Windows Joker 插件。查询失败会直接显示中转错误，不会切回本地旧数据源。

如果网页返回 404，请确认中转域名指向启用了远程同步数据模式的网页实例，且该实例已收到对应群的授权绑定与配置快照。

Linux 网页处理查询时，会按 `scum中转/SCUM中转站接口文档.md` 调用 BattleMetrics 中转站：关键词查询使用 `/api/search?q=...`，数字服务器 ID 使用 `/api/servers/{serverId}`。关键词结果直接采用中转搜索响应；需要在线状态等详情时，再用搜索结果中的 ID 单独查询。成功结果不附加中转抓取时间，搜索列表也不会附加逐条详情失败说明。在 Linux 的 `web_client/.env` 中设置 `SCUM_RELAY_KEY`，值与中转站服务器 `.env` 中的 `RELAY_API_KEY` 一致；不要将此 Key 配置到 Windows 插件或公开前端。默认中转地址为 `https://ba.yooyun.top`，需要自建时可通过 `SCUM_RELAY_URL` 覆盖。

搜索支持中文和数字关键词。详情查询要求数字服务器 ID；群内可用 `/查询1 41568549` 查询单台服务器，也可用 `/绑定id 41568549` 或 `/id绑定 41568549` 设置本群在线查询绑定。当前只开放关键词搜索和服务器详情查询；旧版 IP:端口、无关键词排行榜和资讯查询入口已移除。搜索结果没有确认状态时会显示“未知”，不会误报离线。
